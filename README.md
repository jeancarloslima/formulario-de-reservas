# 🏨 Motor de Reservas

Um sistema de reserva de hotel multi-etapas desenvolvido para oferecer uma experiência de utilizador fluida, utilizando as tecnologias mais modernas do ecossistema React.

## 🚀 Sobre o Projeto

Este projeto é um formulário de reserva funcional que guia o utilizador através de quatro etapas principais: seleção de datas, escolha de quarto, preenchimento de dados pessoais e confirmação final. Foi construído com foco em performance, acessibilidade e gestão de estado eficiente.

## ✨ Funcionalidades

- **Navegação Multi-etapas**: Fluxo dividido para reduzir a carga cognitiva do utilizador.
- **Gestão de Estado Global**: Utilização do **Zustand** para manter os dados da reserva íntegros entre as trocas de tela.
- **Calendário Interativo**: Seleção de datas.
- **Interface Responsiva**: Design adaptável construído com **Tailwind CSS** e componentes do **shadcn/ui**.
- **Barra de Progresso**: Feedback visual constante sobre o progresso da reserva.
- **Resumo e Confirmação**: Revisão de todos os dados antes da submissão final.

## 🛠️ Tecnologias Utilizadas

- **React** (Vite)
- **Zustand**: Gestão de estado simples e performática.
- **Tailwind CSS**: Estilização baseada em utilitários.
- **shadcn/ui**: Componentes de interface acessíveis.
- **date-fns**: Manipulação e formatação de datas.

## 🚀 Como executar localmente

1. Clone o repositório:
`git clone https://github.com/jeancarloslima/formulario-de-reservas.git`
2. Aceda à pasta do projeto:
`cd formulario-de-reservas`
3. Instale as dependências:
`npm install`
4. Inicie o ambiente de desenvolvimento:
`npm run dev`
